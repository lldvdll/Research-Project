\begin{itemize}
    \item Catastrophic forgetting is a well-known failure of artificial neural networks trained sequentially, and stands in contrast to the gradual, graceful decay of learned skills and memories observed in humans.
    \item Song and Bogacz (2024) claim that a specific energy-based learning rule, prospective configuration in a predictive coding network, forgets less than backpropagation, and attribute this to improved target alignment during learning.
    \item This report tests that claim under a controlled, matched protocol, and separately investigates where and how forgetting occurs in the network regardless of which rule is used.
\end{itemize}
