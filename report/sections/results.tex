\subsubsection{Early Stopping Criteria}
\wordcount{250}
\begin{itemize}
    \item A fixed training budget lets metric values swing substantially, since different methods spend a fixed number of updates at very different points in learning.
    \item An accuracy-based stopping threshold is intended to remove this confound by comparing methods once each has demonstrably learned the task to the same standard.
\end{itemize}

\subsection{Where is Forgetting?}
\wordcount{800}
\begin{itemize}
    \item Masking the loss so that absent-class output units receive no gradient recovers retention, and does so regardless of which loss or target coding is used underneath.
    \item Freezing the output layer's weights outright recovers almost nothing, which is a different lever from masking: freezing blocks legitimate new-task learning as well as the destructive part, and the two roughly cancel.
    \item The hidden code retains far more class-1 information than the output layer reports, most starkly in Class-IL (ordinary readout 0\%, probe $\sim$80\%) but present in Domain-IL too.
\end{itemize}
